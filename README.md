# Accredian Enterprise Landing Page

A modern, responsive landing page inspired by the Accredian Enterprise website, built using Next.js, TypeScript, and Tailwind CSS. The project focuses on clean UI, responsive design, reusable components, and production-ready code.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/rajansharma-123/accredian-enterprise.git
```

Go to the project folder:

```bash
cd accredian-enterprise
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

## 🏗️ Build

```bash
npm run build
```
